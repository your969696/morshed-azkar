## كيف تساهم

### 1. Fork المشروع

اضغط على زر **Fork** في أعلى الصفحة.

### 2. استنساخ المشروع

```bash
git clone https://github.com/your-username/morshed-azkar.git
cd morshed-azkar
```

### 3. إنشاء Branch جديد

```bash
git checkout -b feature/اسم-الميزة
```

### 4. اكتب الكود

- اكتب كود نظيف وواضح
- أضف تعليقات بالعربي على الدوال المهمة
- تأكد من أن الكود يعمل بدون أخطاء
- اتبع أسلوب الكود الموجود في المشروع

### 5. اختبر التغييرات

```bash
# بناء التطبيق
npm run build

# فحص الأخطاء
npm run lint
```

### 6. Commit واضح

```bash
git commit -m "إضافة: وصف مختصر للتغيير"
```

### 7. Push التغييرات

```bash
git push origin feature/اسم-الميزة
```

### 8. افتح Pull Request

اذهب إلى صفحة المشروع على GitHub واضغط **New Pull Request**.

## أنواع المساهمات

### إصلاح أخطاء
- إصلاح خطأ في الكود
- تحسين الأداء
- إصلاح مشكلة في واجهة المستخدم

### إضافة ميزات
- إضافة ميزة جديدة
- تحسين ميزة موجودة
- إضافة لغة جديدة

### تحسين التوثيق
- إضافة تعليقات
- تحسين README
- إضافة أمثلة

## أسلوب الكود

### JavaScript/JSX
- استخدم 2 مسافات للإظهار
- استخدم `camelCase` للأسماء
- استخدم `PascalCase` للمكونات

### CSS/Tailwind
- استخدم أسماء واضحة للـ classes
- تجنب التكرار

---

## الإبلاغ عن أخطاء

1. افتح issue جديد
2. اختر نوع **Bug Report**
3. اكتب وصفاً واضحاً للمشكلة
4. أضف خطوات إعادة الإنتاج
5. أضف لقطة شاشة إن أمكن

---

## طلب ميزة

1. افتح issue جديد
2. اختر نوع **Feature Request**
3. اكتب وصفاً واضحاً للميزة
4. اشرح كيف ستفيد المستخدمين

---

## فتح Pull Request

1. تأكد من أن الكود يعمل
2. اكتب وصفاً واضحاً للتغييرات
3. أضف لقطة شاشة إن أمكن
4. انتظر المراجعة

---

## قواعد مهمة

1. **احترام الجميع:** تواصل باحترام مع المساهمين الآخرين
2. **الصبر:** قد تستغرق مراجعة الـ PR وقتاً
3. **الجودة:** تأكد من جودة الكود قبل الإرسال
4. **التوثيق:** وثّق التغييرات التي أجريتها
